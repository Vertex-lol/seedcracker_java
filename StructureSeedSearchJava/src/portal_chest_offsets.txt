# Portal chest offsets for ruined portal templates.
# Format:
#   portal_type, size_x, size_z, chest_offset_x, chest_offset_z
#
# Notes:
# - portal_type matches the portal template name (portal_1..portal_10, giant_portal_1..3).
# - offsets are block coords from the structure start block (chunk start) to the chest block.
# - size_x/size_z come from the structure bounding box.
# - the code expands these to all rotations and mirrors (mirror applied before rotation).
#
